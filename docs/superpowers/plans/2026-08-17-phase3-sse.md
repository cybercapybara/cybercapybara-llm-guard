# LLM Guard — Phase 3 (SSE processing) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Token-by-token demasking of streamed LLM responses: the shared SSE frame machinery plus the three dialect processors (chat_completions / messages / responses), corpora ported from Go first — the single hardest subsystem of the project (spec §6 risk callout).

**Architecture:** `src/guard/sse/` — header-only, no HTTP deps. `Common.hpp` (frame split/classify/build, JSONCloseTracker, MaskedTextRecorder), one processor header per dialect implementing `process_chunk(chunk, end_of_stream) → emitted bytes`, and `Sse.hpp` facade (`make_processor(format, config…)` + byte-identical passthrough + response-side SSE detection). Demaskers (Phase 2) are per-(stream-key, field), created from the request's `MaskingState` Config.

**Tech Stack:** existing deps only. Go authority carries the detail per project convention: `internal/sseproc/**` — port semantics AND test corpora exhaustively (chatcompletions processor_test.go 3823 lines; messages 800; responses 603).

**Spec:** `docs/superpowers/specs/2026-08-14-llm-guard-design.md` §6

## Global Constraints

All Phase-1/2 constraints hold verbatim: NO local builds (CI only, no Docker/colima), header-only `src/`, clang-format 17/120 cols, conventional commits, NO AI trailers, branch-per-task + PR + 8/8 + controller review before merge. Plus:
- **Corpora are the authority**: port Go's processor test tables case-for-case BEFORE/WITH the implementation; a failing ported case is an implementation bug — never edit the case (transcription errors excepted, diff against Go to prove).
- Phase-2 handoffs bind: one Demasker per streamed field, never shared; `DemaskError::unemitted` MUST be emitted by every caller (fail-open, lossless); structural-vs-plain selection by arguments-key rule; `demask_json_arguments` naive-path shape-change decision is made HERE for tool fragments — follow Go exactly (naive first + validity check), ledger any deviation.
- Frames re-emitted must use `Guard::Json` encoding (no HTML escaping) — placeholders `<X_1>` survive byte-exact.
- Fail-open: any processor error → emit the raw un-processed bytes (passthrough degradation), never drop or corrupt; port Go's exact fallback sites.

## Phase-3 shared interfaces

```cpp
// src/guard/sse/Common.hpp
namespace Guard::Sse {
struct FrameSplit { std::vector<std::string_view> frames; std::string_view tail; };
FrameSplit split_frames(std::string_view buf);           // \n\n | \r\n\r\n, carried tail
enum class FrameKind { Event, Done, Passthrough };
struct ClassifiedFrame { FrameKind kind; std::string data;    // joined multi-line data: payload
                         std::string_view raw; };
ClassifiedFrame classify_frame(std::string_view frame);  // data: with/without space; [DONE]
std::string build_event_frame(std::string_view data);    // mirrors Go BuildEventFrame exactly
class JsonCloseTracker {                                  // brace depth, in-string+escape state
  public:                                                 //   carried ACROSS fragments
    void feed(std::string_view fragment);
    bool closed() const;                                  // top-level object completed
    void reset();
};
class MaskedTextRecorder {                                // audit capture, first-seen order per key
  public:
    void record(const std::string& key, std::string_view text);
    std::vector<std::string> texts() const;
};
}
```

```cpp
// src/guard/sse/Sse.hpp
namespace Guard::Sse {
class Processor {                                         // dialect-agnostic contract
  public:
    virtual ~Processor() = default;
    // Feed one upstream chunk; returns bytes to emit to the client NOW.
    // end_of_stream flushes everything. NEVER throws: internal errors degrade
    // to emitting unprocessed raw bytes (fail-open), mirroring Go.
    virtual std::string process_chunk(std::string_view chunk, bool end_of_stream) = 0;
    virtual const MaskedTextRecorder* recorder() const { return nullptr; }
};
std::unique_ptr<Processor> make_processor(Guard::ApiFormat format,
                                          const Guard::Demask::Config& cfg,
                                          bool record_masked_texts);
std::unique_ptr<Processor> make_passthrough();            // byte-identical relay
// Response-side SSE detection (spec §6): Content-Type contains text/event-stream,
// OR request wanted stream && response Content-Type is not application/json.
bool is_sse_response(std::string_view content_type, bool request_wanted_stream);
}
```

Per-dialect headers: `ChatCompletionsProcessor.hpp`, `MessagesProcessor.hpp`, `ResponsesProcessor.hpp` (each exposes `make_*_processor(cfg, record)` consumed by the facade; internals private to the header).

## Tasks

### Task 3.1: SSE common machinery
Port `internal/sseproc/common/` (frames.go, json.go usage, recorder — read the actual file set) + its tests exhaustively. Key semantics: split on both separators with tail carry; `data:` classification incl. optional space and multi-line joins; `[DONE]`; comment/`event:`/`id:` lines passthrough per Go; JSONCloseTracker string/escape state across 1-byte fragments (torture tests); recorder first-seen key order. Branch `feat/guard-sse-common`. Files: `src/guard/sse/Common.hpp`, `tests/unit/test_guard_sse_common.cpp`.

### Task 3.2: chat_completions processor (+ full corpus)
Port `internal/sseproc/chatcompletions/` (761 lines) + processor_test.go (3823 lines) case-for-case. Demaskers keyed `(choice_index, tool_call_index, field)`, field ∈ content|reasoning|tool_arguments, tool_call_index −1 for legacy function_call; aggregator for merged chunk metadata; first content delta flushes reasoning demasker; JSON demasker for tool fragments flushed on JsonCloseTracker close; combined content+finish frame split (finish/usage nulled + metadata-only frame); role-only/refusal/audio/keepalive verbatim without flushing; `[DONE]` and EOS-without-DONE flush all. Branch `feat/guard-sse-cc`. Files: `src/guard/sse/ChatCompletionsProcessor.hpp`, `tests/unit/test_guard_sse_cc.cpp` (corpus may split into a data file if >150KB — implementer's call, document).

### Task 3.3: messages processor (+ corpus)
Port `internal/sseproc/messages/` + 800-line test. content_block_start records type (text|thinking|tool_use|redacted_thinking); deltas: text_delta.text / thinking_delta.thinking / input_json_delta.partial_json (JSON demasker); content_block_stop flushes; message_start/ping/message_delta/message_stop byte-for-byte. Branch `feat/guard-sse-msg`. Files: `src/guard/sse/MessagesProcessor.hpp`, `tests/unit/test_guard_sse_msg.cpp`.

### Task 3.4: responses processor (+ corpus)
Port `internal/sseproc/responses/` + 603-line test. Delta events demasked streaming; snapshot events (`*.done`, `response.completed/incomplete/failed`) re-send full text → fresh one-shot demasker each (uses Phase-2 `extract_response_output_fields` base-path API); processor owns outgoing `sequence_number` (outSeq init −1, synthetic frames renumber); item_id tracking per key. Branch `feat/guard-sse-resp`. Files: `src/guard/sse/ResponsesProcessor.hpp`, `tests/unit/test_guard_sse_resp.cpp`.

### Task 3.5: facade + fragmentation torture + audit recording
`Sse.hpp`: make_processor dispatch, passthrough processor (+ unknown-format counter hook point — a callback, no metrics dep), is_sse_response (port gateway's exact detection incl. mislabeled-upstream rule). Cross-dialect torture test: for each dialect, take a realistic multi-frame stream, feed at EVERY chunk size 1..64 and at every split position (loops), assert output byte-identical to whole-stream processing AND placeholders from a real request MaskingState restored (production two-transaction shape from Phase 2's round-trip). MaskedTextRecorder wired per dialect (tool fragments excluded per Go). Branch `feat/guard-sse-facade`. Files: `src/guard/sse/Sse.hpp`, `tests/unit/test_guard_sse_facade.cpp`.
